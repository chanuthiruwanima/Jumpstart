### 2D Mini Platformer
Navigate through the level and avoid the crab enemy
Made using Godot


## How to play
Use the WASD/arrow keys to move

- Move: 'A'/'D', or Left/Right arrow keys
- Jump: 'W' or Up arrow key or 'Space'
- Shoot: Left mouse click
